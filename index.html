🛠 GitHub Pages 設定步驟

Step 1 — 新建一個 GitHub repo，名稱例如 md-viewer

Step 2 — 上傳 viewer.html，改名為 index.html

Step 3 — Settings → Pages → Branch: main → Save

Step 4 — 幾分鐘後拿到網址，填入上方 Viewer 網址欄位
